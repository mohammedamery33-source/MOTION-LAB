# VISORA Studio v4

New features:
- Image detail specifications: suggested image pixel dimensions, aspect ratio, intended device/display size, palette family, material, and visual style.
- Device filters: desktop wallpaper, phone wallpaper, tablet, square/social.
- Additional filters for color family, material, and style.
- Personal moodboards stored in the current browser with create, view, add references, and delete actions.
- Responsive layout, lazy-loaded remote images, progressive batches, search, save, and download.
- Custom VISORA favicon.

Important sizing note:
The displayed dimensions are suggested target/export sizes for each reference type, not verified native dimensions of the remote source image. Phone screen aspect ratios vary by model; exact device wallpaper sizing should be selected by model in a future update. This prototype's boards are stored in localStorage on this browser and are not synced between devices.

Image-source note:
The feed uses seeded remote sample photos. It is not a curated or license-cleared design reference archive. The image host and internet connection affect availability and download behavior.
