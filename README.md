# MOTION LAB

A responsive single-page automotive concept showcase built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools or installs are needed.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `MOTION-LAB`.
2. Upload `index.html`, `favicon.svg`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait a few minutes and open the URL GitHub shows on the Pages screen.

## Features
- Responsive mobile and desktop layout
- Build filtering and text search
- Concept detail modals
- Saved favorites stored locally in the current browser
- Build brief configurator with copy-to-clipboard
- English / Arabic interface toggle
- Keyboard-accessible modal close and reduced-motion support

## Notes
- This is a static concept website, not a real 3D configurator or online store.
- Vehicle photos are loaded from Unsplash and require an internet connection.
- Build names, descriptions, and budget ranges are illustrative only; they are not quotes or verified technical specifications.
- Favorites are stored only in the browser being used.
